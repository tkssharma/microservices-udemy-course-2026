Publish/Subscribe Pattern

sequenceDiagram
    participant OS as Order Service
    participant EB as Event Bus
    participant IS as Inventory Service
    participant NS as Notification Service
    participant AS as Analytics Service
    
    OS->>EB: Publish: OrderCreated
    
    par Parallel Processing
        EB->>IS: Deliver Event
        IS->>IS: Reserve Stock
    and
        EB->>NS: Deliver Event
        NS->>NS: Send Confirmation Email
    and
        EB->>AS: Deliver Event
        AS->>AS: Update Metrics
    end
    
    IS-->>EB: ACK
    NS-->>EB: ACK
    AS-->>EB: ACK
    
    Note over EB: Events are processed independently

Complete Event Flow

flowchart LR
    A[User Action] --> B[API Gateway]
    B --> C[Order Service]
    C --> D[(Order DB)]
    C -->|OrderCreated| E[Kafka]
    
    E --> F[Payment Service]
    F --> G[(Payment DB)]
    F -->|PaymentProcessed| E
    
    E --> H[Inventory Service]
    H --> I[(Inventory DB)]
    H -->|StockReserved| E
    
    E --> J[Notification Service]
    J -->|Send Email| K[Email Provider]
    
    E --> L[Analytics Service]
    L --> M[(Analytics DB)]
