# Module 07: Event-Driven Architecture

This module covers event-driven architecture patterns for building loosely coupled, scalable microservices systems.

---

## Lessons in This Module

| Lesson | Topic                                       | Duration |
| ------ | ------------------------------------------- | -------- |
| 7.1    | Event-Driven Fundamentals                   | 20 min   |
| 7.2    | Event Types (Domain, Integration, Commands) | 20 min   |
| 7.3    | Message Brokers (RabbitMQ, Kafka, Redis)    | 25 min   |
| 7.4    | Pub/Sub Pattern                             | 20 min   |
| 7.5    | Event Storming                              | 15 min   |

---

## Learning Objectives

By the end of this module, you will be able to:

- Understand event-driven architecture principles
- Differentiate between event types
- Choose the right message broker for your needs
- Implement pub/sub patterns
- Use Event Storming for domain discovery
