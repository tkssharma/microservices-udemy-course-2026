# Module 04: API Gateway Pattern

This module covers the API Gateway pattern, a critical component in microservices architecture that serves as the single entry point for all client requests.

---

## Lessons in This Module

| Lesson | Topic                                  | Duration |
| ------ | -------------------------------------- | -------- |
| 4.1    | What is an API Gateway?                | 15 min   |
| 4.2    | Gateway Responsibilities               | 20 min   |
| 4.3    | Building a Custom Gateway with Express | 30 min   |
| 4.4    | Backend for Frontend (BFF) Pattern     | 20 min   |
| 4.5    | API Gateway Best Practices             | 15 min   |

---

## Learning Objectives

By the end of this module, you will be able to:

- Understand the role of an API Gateway in microservices
- Identify key responsibilities of a gateway
- Build a custom API Gateway using Express and TypeScript
- Implement the BFF pattern for different clients
- Apply best practices for gateway design
