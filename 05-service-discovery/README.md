# Module 05: Service Discovery

This module covers service discovery patterns that enable microservices to find and communicate with each other in dynamic environments.

---

## Lessons in This Module

| Lesson | Topic                                | Duration |
| ------ | ------------------------------------ | -------- |
| 5.1    | Why Service Discovery?               | 15 min   |
| 5.2    | Client-Side vs Server-Side Discovery | 20 min   |
| 5.3    | Service Registry Patterns            | 20 min   |
| 5.4    | Health Checking and Load Balancing   | 20 min   |
| 5.5    | Service Discovery in Kubernetes      | 15 min   |

---

## Learning Objectives

By the end of this module, you will be able to:

- Understand why service discovery is needed in microservices
- Compare client-side and server-side discovery patterns
- Implement service registration and discovery
- Configure health checks for service instances
- Understand Kubernetes native service discovery
