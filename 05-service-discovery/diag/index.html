🔍 Service Discovery

Client-Side Discovery Pattern

sequenceDiagram
    participant C as Client Service
    participant R as Service Registry
    participant S1 as Service Instance 1
    participant S2 as Service Instance 2
    participant S3 as Service Instance 3
    
    C->>R: Query: Where is Order Service?
    R-->>C: [Instance1:8081, Instance2:8082, Instance3:8083]
    
    Note over C: Client-side Load Balancing
    
    C->>S1: Request (Round Robin)
    S1-->>C: Response
    
    C->>S2: Request (Round Robin)
    S2-->>C: Response
    
    C->>S3: Request (Round Robin)
    S3-->>C: Response

Health Check Flow

sequenceDiagram
    participant S as Service Instance
    participant R as Service Registry
    participant LB as Load Balancer
    
    loop Every 30 seconds
        S->>R: Heartbeat (I'm alive!)
        R-->>S: ACK
    end
    
    Note over S: Service becomes unhealthy
    
    S--xR: Heartbeat timeout
    R->>R: Mark instance unhealthy
    R->>LB: Update: Remove unhealthy instance
    LB->>LB: Remove from rotation
    
    Note over S: Service recovers
    
    S->>R: Re-register
    R->>R: Health check passes
    R->>LB: Update: Add healthy instance
    LB->>LB: Add to rotation
