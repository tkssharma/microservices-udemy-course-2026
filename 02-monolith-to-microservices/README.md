# Module 02: Monolith to Microservices

This module covers strategies and patterns for migrating from a monolithic architecture to microservices.

---

## Lessons in This Module

| Lesson | Topic                          | Duration |
| ------ | ------------------------------ | -------- |
| 2.1    | Understanding Your Monolith    | 15 min   |
| 2.2    | Domain-Driven Design Basics    | 25 min   |
| 2.3    | Identifying Service Boundaries | 20 min   |
| 2.4    | Strangler Fig Pattern          | 20 min   |
| 2.5    | Decomposition Strategies       | 20 min   |
| 2.6    | Migration Best Practices       | 15 min   |

---

## Learning Objectives

By the end of this module, you will be able to:

- Analyze a monolith to identify migration candidates
- Apply Domain-Driven Design concepts to find service boundaries
- Use the Strangler Fig pattern for incremental migration
- Choose appropriate decomposition strategies
- Avoid common migration pitfalls
