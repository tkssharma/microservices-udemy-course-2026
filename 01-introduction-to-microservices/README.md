# Module 01: Introduction to Microservices

This module covers the fundamentals of microservices architecture, helping you understand what microservices are, why they exist, and when to use them.

---

## Lessons in This Module

| Lesson | Topic                            | Duration |
| ------ | -------------------------------- | -------- |
| 1.1    | What are Microservices?          | 15 min   |
| 1.2    | Microservices vs Monolith vs SOA | 20 min   |
| 1.3    | Benefits of Microservices        | 15 min   |
| 1.4    | Challenges of Microservices      | 15 min   |
| 1.5    | Key Characteristics              | 15 min   |
| 1.6    | When to Use Microservices        | 10 min   |

---

## Learning Objectives

By the end of this module, you will be able to:

- Define microservices architecture clearly
- Compare microservices with monolith and SOA
- Identify benefits and trade-offs
- Recognize when microservices are the right choice
- Understand key characteristics of well-designed microservices
