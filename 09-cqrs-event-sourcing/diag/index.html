Event Replay & Projection Rebuild

sequenceDiagram
    participant ES as Event Store
    participant PR as Projection Rebuilder
    participant NP as New Projection
    participant DB as New Read DB
    
    Note over PR: Deploy new projection version
    
    PR->>ES: Request all events from beginning
    
    loop For each event
        ES->>PR: Event 1: OrderCreated
        PR->>NP: Apply event
        NP->>DB: Update projection
        
        ES->>PR: Event 2: ItemAdded
        PR->>NP: Apply event
        NP->>DB: Update projection
        
        ES->>PR: Event N: ...
        PR->>NP: Apply event
        NP->>DB: Update projection
    end
    
    Note over DB: Projection rebuilt with new schema
    
    PR->>PR: Switch traffic to new projection
