# Module 09: CQRS and Event Sourcing

This module covers Command Query Responsibility Segregation (CQRS) and Event Sourcing patterns for building scalable, auditable microservices systems.

---

## Lessons in This Module

| Lesson | Topic                     | Duration |
| ------ | ------------------------- | -------- |
| 9.1    | CQRS Fundamentals         | 20 min   |
| 9.2    | Read vs Write Models      | 20 min   |
| 9.3    | Event Sourcing Basics     | 25 min   |
| 9.4    | Event Store               | 20 min   |
| 9.5    | Projections and Snapshots | 20 min   |

---

## Learning Objectives

By the end of this module, you will be able to:

- Understand CQRS and when to apply it
- Design separate read and write models
- Implement event sourcing for audit trails
- Build an event store
- Create projections and use snapshots for performance
