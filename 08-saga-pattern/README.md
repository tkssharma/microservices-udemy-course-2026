# Module 08: Saga Pattern

This module covers the Saga pattern for managing distributed transactions across multiple microservices without using traditional two-phase commit.

---

## Lessons in This Module

| Lesson | Topic                            | Duration |
| ------ | -------------------------------- | -------- |
| 8.1    | Distributed Transactions Problem | 15 min   |
| 8.2    | Saga Pattern Overview            | 20 min   |
| 8.3    | Choreography vs Orchestration    | 25 min   |
| 8.4    | Compensation Transactions        | 20 min   |
| 8.5    | Saga Implementation              | 25 min   |

---

## Learning Objectives

By the end of this module, you will be able to:

- Understand why distributed transactions are problematic
- Implement the Saga pattern for data consistency
- Choose between choreography and orchestration
- Design compensation transactions
- Build a complete saga implementation
