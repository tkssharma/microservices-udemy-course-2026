# Module 03: Communication Patterns

This module covers the different ways microservices communicate with each other, including synchronous and asynchronous patterns.

---

## Lessons in This Module

| Lesson | Topic                                     | Duration |
| ------ | ----------------------------------------- | -------- |
| 3.1    | Synchronous vs Asynchronous Communication | 20 min   |
| 3.2    | REST API Communication                    | 25 min   |
| 3.3    | gRPC Communication                        | 25 min   |
| 3.4    | Message Queues (RabbitMQ)                 | 30 min   |
| 3.5    | Event-Based Communication                 | 25 min   |
| 3.6    | Choosing the Right Pattern                | 15 min   |

---

## Learning Objectives

By the end of this module, you will be able to:

- Understand the difference between sync and async communication
- Implement REST APIs for service-to-service communication
- Use gRPC for high-performance communication
- Implement message queues with RabbitMQ
- Design event-based communication patterns
- Choose the right communication pattern for your use case
