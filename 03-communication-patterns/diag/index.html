Webhooks (HTTP Callbacks)

sequenceDiagram
    participant APP as Your App
    participant SVC as External Service
    participant WH as Webhook Endpoint
    
    APP->>SVC: Register Webhook URL
    SVC-->>APP: Webhook Registered
    
    Note over SVC: Event Occurs
    
    SVC->>WH: POST /webhook (Event Payload)
    WH->>WH: Verify Signature
    WH->>WH: Process Event
    WH-->>SVC: 200 OK
    
    Note over APP,SVC: Examples: Stripe, GitHub, Twilio
    
    rect rgb(99, 102, 241, 0.2)
        Note over WH: Retry Logic
        SVC->>WH: Retry 1 (if failed)
        SVC->>WH: Retry 2 (exponential backoff)
        SVC->>WH: Retry 3 (final attempt)
    end
