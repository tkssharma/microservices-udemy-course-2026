Network Protocols
TCP • UDP • HTTP • HTTPS • WebSocket

TCP (Transmission Control)

  • Reliable, ordered delivery
  • Connection-oriented
  • Error checking & recovery
  • Use: Web, Email, File Transfer

UDP (User Datagram)

  • Fast, no guarantee
  • Connectionless
  • No error recovery
  • Use: Streaming, Gaming, DNS

  • No encryption

  • Data integrity verified
  • Server authentication
  • SEO ranking boost

GraphQL
Query Language for APIs

GraphQL Advantages

  • Single endpoint
  • Client specifies data needed
  • No over-fetching
  • Strong typing with schema

REST Advantages

  • Simple & well-understood
  • HTTP caching built-in
  • Stateless by design
  • Better for simple CRUD
query {
  user(id: "123") {
    name
    email
    orders { id, total }
  }
}

When to Use?

REST for simple APIs • GraphQL for complex, nested data requirements

REST vs GraphQL
📡
REST
vs
◈
GraphQL
R

Multiple Endpoints

REST: /users, /posts, /comments → GraphQL: Single /graphql endpoint

G

Data Fetching

REST: Multiple round trips → GraphQL: One request, exact data

R

Caching

REST: HTTP caching easy → GraphQL: Requires custom caching

G

Versioning

REST: /v1/users, /v2/users → GraphQL: Evolve schema, deprecate fields

Scaling Strategies

⬆️ Vertical Scaling (Scale Up)

  • Add more CPU, RAM, Storage
  • Single machine upgrade
  • Simpler architecture
  • Hardware limits exist

↔️ Horizontal Scaling (Scale Out)

  • Add more machines/instances
  • Distributed system
  • Requires load balancer
  • Unlimited scalability

Monolith vs Microservices

🏢 Monolith

  • Single deployable unit
  • Shared database
  • Simple to develop initially
  • Harder to scale specific parts

🔷 Microservices

  • Independent services
  • Own database per service
  • Scale services independently
  • Complex infrastructure

Database Scaling
Replication • Sharding • Partitioning

📋 Replication

  • Copy data to multiple nodes
  • Master-Slave / Primary-Replica
  • Read scalability
  • High availability

🔪 Sharding

  • Split data across nodes
  • Horizontal partitioning
  • Write scalability
  • Complex queries harder

✅

CP Systems

  • MongoDB, Redis, HBase
  • Consistency + Partition Tolerance
  • May reject requests during partition

AP Systems

  • Cassandra, DynamoDB, CouchDB
  • Availability + Partition Tolerance
  • Eventually consistent
