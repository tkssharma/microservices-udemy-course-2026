⚙️ External Task Pattern

How It Works

1
Workflow reaches task
Task added to queue with topic
2
Worker polls for tasks
fetchAndLock by topic
3
Execute business logic
Call microservices
4
Complete or fail task
Workflow continues

Node.js Worker Example

const client = new Client({
  baseUrl: "http://camunda:8080/engine-rest"
});

client.subscribe("credit-check", 
  async ({ task, taskService }) => {
    
  const customerId = task.variables
    .get("customerId");
  
  const score = await creditService
    .checkScore(customerId);
  
  await taskService.complete(task, {
    creditScore: score,
    approved: score > 700
  });
});

🚌 Camunda as Event Bus

❌ Traditional Event Bus

  • • Just passes events
  • • No state tracking
  • • No sequence enforcement
  • • No compensation

✅ Camunda as Event Bus

  • • Manages overall state
  • • Enforces business sequence
  • • Built-in error handling
  • • Automatic compensation
