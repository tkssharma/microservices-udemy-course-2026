# Workflow Orchestration Complete Course

## 📚 Course Structure

This course covers everything about Workflow Orchestration in Microservices.

### Module 1: Fundamentals
- **01-what-is-workflow-orchestration/** - Introduction & Core Concepts
- **02-why-we-need-workflow-orchestration/** - Problems & Solutions

### Module 2: Use Cases & Patterns
- **03-real-world-use-cases/** - Industry Examples & Patterns
- **04-workflow-in-age-of-ai/** - BPMN + AI Agents

### Module 3: Implementation
- **05-workflow-with-microservices/** - Architecture & Implementation
- **06-popular-tools-comparison/** - Temporal vs Camunda vs Step Functions

---

## 🎯 Learning Outcomes

By the end of this course, you will:
- Understand what workflow orchestration is and why it matters
- Know when to use orchestration vs choreography
- Implement workflows with popular tools
- Design workflows for AI-powered applications
- Build production-ready microservices orchestration
