🗄️ Database Patterns

Database per Service Pattern

flowchart TB
    subgraph Services
        US[👤 User Service]
        OS[📦 Order Service]
        PS[💳 Payment Service]
        IS[📊 Inventory Service]
    end
    
    subgraph Databases["Private Databases"]
        DB1[(User DB
PostgreSQL)]
        DB2[(Order DB
MongoDB)]
        DB3[(Payment DB
PostgreSQL)]
        DB4[(Inventory DB
Redis)]
    end
    
    US --> DB1
    OS --> DB2
    PS --> DB3
    IS --> DB4
    
    US <-->|API calls| OS
    OS <-->|Events| PS
    OS <-->|Events| IS
    
    style DB1 fill:#6366f1
    style DB2 fill:#10b981
    style DB3 fill:#f59e0b
    style DB4 fill:#ec4899

Shared Database (Anti-Pattern)

flowchart TB
    subgraph Services
        S1[Service A]
        S2[Service B]
        S3[Service C]
    end
    
    subgraph SharedDB["⚠️ Shared Database"]
        T1[users table]
        T2[orders table]
        T3[payments table]
    end
    
    S1 --> T1
    S1 --> T2
    S2 --> T1
    S2 --> T2
    S2 --> T3
    S3 --> T2
    S3 --> T3
    
    style SharedDB fill:#ef4444
    
    Note1[❌ Tight Coupling]
    Note2[❌ Schema Changes Affect All]
    Note3[❌ Single Point of Failure]

Data Synchronization Patterns

flowchart TB
    subgraph Pattern1["Event-Driven Sync"]
        S1[Order Service]
        EV1[OrderCreated Event]
        S2[Inventory Service]
        DB1[(Order DB)]
        DB2[(Inventory DB)]
    end
    
    S1 -->|write| DB1
    S1 -->|publish| EV1
    EV1 -->|consume| S2
    S2 -->|update| DB2
    
    subgraph Pattern2["Change Data Capture"]
        SRC[(Source DB)]
        CDC[CDC Connector
Debezium]
        KAFKA[Kafka]
        TGT[(Target DB)]
    end
    
    SRC -->|binlog| CDC
    CDC -->|stream| KAFKA
    KAFKA -->|replicate| TGT
    
    style EV1 fill:#7c3aed
    style KAFKA fill:#7c3aed
    style CDC fill:#10b981
