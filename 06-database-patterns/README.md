# Module 06: Database Patterns

This module covers database strategies for microservices, including the database-per-service pattern, data consistency challenges, and synchronization techniques.

---

## Lessons in This Module

| Lesson | Topic                         | Duration |
| ------ | ----------------------------- | -------- |
| 6.1    | Database per Service Pattern  | 20 min   |
| 6.2    | Shared Database Anti-Pattern  | 15 min   |
| 6.3    | Data Consistency Strategies   | 25 min   |
| 6.4    | Data Synchronization Patterns | 25 min   |
| 6.5    | Polyglot Persistence          | 15 min   |

---

## Learning Objectives

By the end of this module, you will be able to:

- Understand why each service should own its data
- Recognize the problems with shared databases
- Implement eventual consistency patterns
- Synchronize data across services
- Choose the right database for each service
